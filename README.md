# Brute Force Password Cracker

A simple Python project that demonstrates how a brute-force password attack works.

The program generates possible combinations of numbers and lowercase letters and compares each combination with the password entered by the user. It continues until a matching combination is found.

This project was created to understand brute-force algorithms, Python's `itertools` module, string manipulation, and the effect of password length on the number of possible combinations.

## Features

* Generates possible password combinations automatically
* Supports numbers (`0-9`) and lowercase letters (`a-z`)
* Tests combinations in increasing order of length
* Counts the number of attempts
* Measures the time taken to find the password
* Displays the current guessing progress during execution
* Uses only Python's standard library

## How It Works

The program first asks the user to enter a password.

It then starts generating combinations using the following character set:

```python
keys = "1234567890abcdefghijklmnopqrstuvwxyz"
```

The program starts with one-character combinations and gradually increases the length of the generated combinations.

For example, the general process looks like:

```text
1
2
3
...
a
b
c
...
11
12
13
...
aa
ab
ac
...
```

Each generated combination is compared with the password entered by the user.

When a match is found, the program displays the password, number of attempts, and execution time.

## Example

If the entered password is:

```text
abc
```

the program eventually reaches:

```text
abc
```

and produces output similar to:

```text
Password found: abc
Attempts: 14701
Time taken: 0.00XXXX seconds
```

The exact execution time depends on the computer and system load.

## Main Python Concepts Used

### `itertools.product()`

`product()` is used to generate every possible combination of the characters in the defined character set.

For example:

```python
product("ab", repeat=2)
```

generates combinations equivalent to:

```text
aa
ab
ba
bb
```

### `perf_counter()`

`perf_counter()` is used to measure the execution time of the password search.

### `join()`

The combinations generated by `product()` are converted into strings using:

```python
''.join(combination)
```

### Attempt Counter

The program keeps track of how many guesses have been tested:

```python
attempts += 1
```

### Progress Display

The program updates the terminal after every 5,000 attempts so that the current progress can be observed without continuously creating new lines.

## Complexity

The number of possible combinations increases exponentially as the password length increases.

With 36 available characters, the number of combinations of exactly length `n` is:

```text
36ⁿ
```

For example:

| Length | Possible Combinations |
| -----: | --------------------: |
|      1 |                    36 |
|      2 |                 1,296 |
|      3 |                46,656 |
|      4 |             1,679,616 |
|      5 |            60,466,176 |
|      6 |         2,176,782,336 |

The total number of attempts can therefore become very large even for relatively short passwords.

This demonstrates why password length and character diversity are important factors in password security.

## Current Limitations

The current version is intentionally simple and has several limitations:

* Only lowercase letters and numbers are included.
* Uppercase letters are not supported.
* Special characters are not supported.
* The password is provided directly by the user.
* The program does not interact with websites or online accounts.
* Performance decreases significantly as the password length increases.
* There is no parallel processing or optimization implemented.
